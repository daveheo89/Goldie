🔗 계약 색인(contractsByDog) 백필 도구

과거에 이미 서명 완료된 계약들에는 "강아지 ID → 계약 ID" 연결고리(contractsByDog)가 없습니다. 이 도구는 기존 contracts 전체를 한 번 훑어서, 파기(cancelled)되지 않은 계약마다 이 연결고리를 만들어줍니다. 이걸 해두면 이미 분양된 손님이 계약서 링크로 다시 들어왔을 때, 본인확인 후 계약서/가이드북을 재다운로드할 수 있습니다.

⚠️ 1회성 도구입니다. 실행은 여러 번 눌러도 안전하지만(이미 있는 연결고리는 덮어쓰기만 함), 실행 전 특별히 백업이 필요하지는 않습니다. 이 도구는 기존 계약 데이터를 읽기만 하고, 새 연결고리 외에는 아무것도 바꾸지 않습니다.

🍼 breedingPublic 백필 도구
